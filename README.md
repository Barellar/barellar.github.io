# Daniel Emenike — Portfolio

Application Security / DevSecOps portfolio for GitHub Pages.

## Deploy

This repository is named `barella.github.io`, so GitHub Pages can publish it at:

`https://barella.github.io`

Go to **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root)**.

## Before publishing

Replace these placeholders in `index.html`:

- `YOUR_EMAIL@example.com`
- `https://www.linkedin.com/in/YOUR-LINKEDIN/`

Replace project links with the repositories you want to feature.
